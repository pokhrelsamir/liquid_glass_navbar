# 🌊 Liquid Glass Navbar

A modern **Liquid Glass UI** demonstration inspired by Apple's glassmorphism design language. This project showcases a realistic liquid glass navigation bar with dynamic refraction, specular highlights, neumorphic components, draggable glass elements, live configuration controls, and smooth animations—all built using **HTML, CSS, and Vanilla JavaScript**.

---

# ✨ Features

- 🌊 Realistic Liquid Glass rendering
- 💎 Dynamic SVG displacement filters
- 🔥 Glass refraction effects
- ✨ Specular light reflections
- 🎨 Adjustable tint and shadow
- 🌓 Light / Dark theme switcher
- 📱 Responsive design
- 🖱️ Interactive draggable glass objects
- 🎯 Animated navigation indicator
- ⚡ Smooth hardware-accelerated animations
- 🎛️ Live configuration panel
- 💾 LocalStorage configuration persistence
- 🧩 Pure HTML, CSS & Vanilla JavaScript
- 🚫 No external JavaScript frameworks

# 💡 How It Works

The liquid glass effect is generated using:

- SVG Filters
- Dynamic displacement maps
- Refraction calculations
- Specular lighting maps
- Gaussian blur
- Backdrop filtering
- Real-time SVG regeneration

Every glass element dynamically rebuilds its filter whenever:

- Window resizes
- Settings change
- Elements are dragged
- Navigation indicator moves
